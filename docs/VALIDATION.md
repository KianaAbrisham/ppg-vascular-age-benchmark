The actual test output is in `test_output.txt`; trained-checkpoint checks are in
`integration_checks.json`. `smoke_results/` contains the recorded environment, small-run metrics and
run configuration. Paths in that configuration identify the validation runtime. The executed notebook
contains actual training, inference and plot outputs. Large checkpoints are intentionally excluded
from this code package and are regenerated by the demo command.

All training here used 72 artificial software-fixture waveforms, one epoch, and random initialization.
Keras models used two outer folds; ResNet used a held-out split. These checks validate the software
workflow, not model convergence, paper metrics, physiological simulation quality or clinical performance.

The original research CSV exports were unavailable. Full PWDB experiments, downloaded ImageNet
initialization, Windows and GPU execution have not been validated in this delivery. The supplied GitHub
Actions workflow has been included but has not run on GitHub before upload.
